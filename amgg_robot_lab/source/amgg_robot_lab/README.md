# AM-DP123 PICO XR Lab (Isaac Lab external extension)

This directory contains the AM-DP123 extension for the official Isaac Lab
`isaaclab_teleop` pipeline. It ships the unmodified AM-DP123 URDF plus meshes,
the public joint/frame/camera contracts, offline URDF kinematics, an 18-D Pink
inverse-kinematics action term, and the PICO XR teleoperation environment
`Isaac-AM-DP123-Pico-XR-v0`.

See `README_CN.md` for the full Chinese documentation, the contract tables, and
the server validation procedure.
